ℹ️ Método reverse()

reverse() invierte el orden de los elementos de un array. El primer elemento pasa a ser el último y viceversa.

  • Modifica el array original
  • Usa [...array].reverse() para no modificar
  • Para invertir un string: split('').reverse().join('')
  • Devuelve el array invertido
