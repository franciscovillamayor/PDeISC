ℹ️ Método includes()

includes() verifica si un elemento está presente en un array y devuelve true o false según corresponda.

  • Sintaxis: array.includes(elemento)
  • Devuelve true o false
  • Distingue entre mayúsculas y minúsculas
  • No modifica el array original
