ℹ️ Método slice()

slice() devuelve una copia superficial de una porción del array en un nuevo array. No modifica el array original.

  • Sintaxis: array.slice(inicio, fin)
  • No modifica el array original
  • Admite índices negativos
  • Devuelve un nuevo array
