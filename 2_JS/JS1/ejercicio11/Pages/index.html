ℹ️ Método filter()

filter() crea un nuevo array con todos los elementos que pasan la prueba implementada por la función proporcionada.

  • Sintaxis: array.filter((elemento) => { return condicion } }
  • Devuelve un nuevo array
  • No modifica el array original
  • El nuevo array solo incluye los elementos que cumplen la condición
