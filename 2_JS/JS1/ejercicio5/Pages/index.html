ℹ️ Método splice()

splice() modifica un array eliminando, reemplazando o agregando elementos en una posición específica.

  • Sintaxis: array.splice(inicio, eliminar, ...agregar)
  • Modifica el array original
  • Devuelve los elementos eliminados
  • Versátil para múltiples operaciones
