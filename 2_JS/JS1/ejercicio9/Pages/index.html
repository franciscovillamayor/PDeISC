ℹ️ Método forEach()

forEach() ejecuta una función para cada elemento del array, sin modificarlo y sin devolver ningún valor.

  • Sintaxis: array.forEach((elemento) => { ... } }
  • No devuelve nada (undefined)
  • No modifica el array original
  • Ideal para efectos secundarios
