ℹ️ Método indexOf()

indexOf() devuelve el primer índice en el que se encuentra un elemento en el array, o -1 si el elemento no está presente.

  • Sintaxis: array.indexOf(elemento)
  • Devuelve el primer índice encontrado
  • Devuelve -1 si no encuentra el elemento
  • Realiza una búsqueda de igualdad estricta
